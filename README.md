A deep learning project that recognizes human emotions from speech audio using MFCC feature extraction and a Convolutional Neural Network (CNN).
# Emotion Recognition from Speech

## 📌 Project Overview

This project recognizes human emotions from speech audio using speech signal processing and deep learning techniques. Audio features are extracted using Mel-Frequency Cepstral Coefficients (MFCC), and a Convolutional Neural Network (CNN) is trained to classify different emotions from speech recordings.

## 🎯 Objective

To build a deep learning model that predicts human emotions from speech audio.

## 📂 Dataset

**RAVDESS (Ryerson Audio-Visual Database of Emotional Speech and Song)**

The dataset contains speech recordings labeled with the following emotions:

* Neutral
* Calm
* Happy
* Sad
* Angry
* Fearful
* Disgust
* Surprised

## 🧠 Model

**Convolutional Neural Network (CNN)**

## 🔄 Project Workflow

1. Import the required libraries.
2. Load the RAVDESS dataset.
3. Extract MFCC features from each audio file.
4. Encode emotion labels.
5. Split the dataset into training and testing sets.
6. Build and train the CNN model.
7. Evaluate the model using test data.
8. Visualize the training and validation accuracy.
9. Save the trained model.

## 📊 Results

The CNN model successfully learned patterns from MFCC features and classified emotions from speech recordings. The model was evaluated using testing accuracy and training history.
